One Monday morning punchline, 200 characters or fewer: "Monday again. My alarm
went off, my motivation didn't, and my coffee filed for overtime." The
program writes it to `/output/entry.txt`; an AI judge pairs punchlines head
to head and crowns the biggest laugh.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
